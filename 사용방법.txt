유튜브 다국어 번역기 + 썸네일  사용 방법
==========================================

실행할 파일: youtube_translator_thumbnail.pyw  (더블클릭)

[처음 한 번만]
  1. install.bat 더블클릭 (설치)
  2. google_translate_api_key.txt 를 이 폴더에 넣기
  3. 프로그램 실행 → [유튜브 로그인] 클릭
     → 작업표시줄에서 새로 열린 크롬 창을 열고 구글 로그인 + 채널 선택
     → YouTube 스튜디오 화면이 보이면 안내창의 [확인] 클릭

[영상 올릴 때마다]
  ① 제목·설명 번역 (기존과 같음)
     - [원본 입력]에 한국어 제목·설명 붙여넣기
     - [목록의 전체 언어 번역 시작] 클릭
     - 번역 결과를 [제목 복사]/[설명 복사]로 복사해서
       스튜디오의 각 언어에 붙여넣기

  ② 썸네일 넣기 (①이 끝난 다음에!)
     - [썸네일] 칸에 동영상 주소 입력
     - [이미지 선택]으로 영문 썸네일 선택
     - [썸네일 등록] 클릭
     → 스튜디오에 등록된 모든 언어에 같은 썸네일이 들어갑니다.
     → 진행 중에는 프로그램이 연 크롬 창을 건드리지 마세요.

  * 제목·설명이 이미 들어가 있는 영상은 ②만 하면 됩니다.
  * 썸네일은 스튜디오에 이미 등록된 언어에만 들어갑니다.
  * 제목·설명은 건드리지 않고, 이미 썸네일이 있는 언어는 건너뜁니다.
  * 중간에 멈춰도 [썸네일 등록]을 다시 누르면 남은 언어만 이어서 합니다.

[채널이 여러 개일 때]  ★중요
  프로그램이 연 크롬은 마지막으로 고른 채널로 계속 들어가 있습니다.
  다른 채널의 영상에 썸네일을 넣을 때는 먼저 채널을 바꿔 주세요.
  1. [유튜브 로그인] 클릭
  2. 열린 크롬에서 오른쪽 위 프로필 아이콘 → 계정 전환 → 작업할 채널 선택
  3. 스튜디오에 그 채널 이름이 보이면 안내창의 [확인]
  4. 동영상 주소, 이미지 선택 → [썸네일 등록]
  * 같은 채널 영상을 계속 작업할 때는 다시 할 필요 없습니다.
  * "언어 표를 찾지 못했습니다" 오류가 나오면 대부분 채널이 달라서입니다.
  * 비공개 영상도 됩니다. 단, 업로드 처리가 끝난 뒤에 하세요.

[언어 추가]
  - [새로운 언어 추가]에서 언어 선택 → [목록에 추가하기]
  - 프로그램을 껐다 켜면 다시 기본 50개로 돌아갑니다.

[문제가 생기면]
  - [진행 기록] 창과, 이 폴더 안 logs 폴더의 캡처 이미지를 보내 주세요.
