# 새 프로그램 3가지 사용 방법

썸네일 만들기 · 일괄 작업 · 노래 순서 맞추기

세 프로그램 모두 `cavn_music` 폴더에 있습니다.
기존 프로그램(CAVN 음악, Flow 이미지·영상, 메뉴, 캡컷 조립)은 그대로입니다.

## 처음 한 번

1. 새 프로그램을 받아 지금 쓰는 폴더에 덮어쓰기 합니다.
   https://github.com/hsparksaeha-source/mike/archive/refs/heads/claude/intelligent-fermi-16lch7.zip
2. 저장소 맨 위 폴더의 `install.bat` 을 한 번 실행합니다.
   썸네일용 캡컷 도구(pycapcut)가 함께 설치됩니다.
   빠뜨려도 썸네일 프로그램이 처음 실행될 때 스스로 설치합니다.

---

## 1. 썸네일 만들기 — `썸네일만들기.bat`

md 파일 맨 아래(유튜브 SEO)의 **썸네일 문구**와 **썸네일 이미지 프롬프트**로 유튜브 썸네일을 만듭니다.

### 순서

1. 캡컷을 **닫습니다.**
2. `썸네일만들기.bat` 을 더블클릭합니다.
3. md 파일을 까만 창에 끌어다 놓고 Enter 를 누릅니다.
4. 읽어 온 문구 목록을 확인하고 `y` 를 누릅니다.
5. Flow 프로젝트가 안 열려 있으면 크롬에서 엽니다. 열리면 까만 창에서 Enter 를 누릅니다.
6. 끝나면 캡컷을 엽니다.

`음악_이미지_자동화.bat` 메뉴에서 `4` 를 골라도 같습니다.

### 만드는 것

- **메인(전곡) 1개, 싱글 3개.** 미사곡·클래식처럼 싱글이 없는 md 는 메인만 만듭니다.
- 곡(트랙)마다 적힌 썸네일 문구는 쓰지 않습니다.
- 문구가 여러 안(한글1, 한글2, 1안, 2안…)이면 **안마다 한 장씩** 만듭니다.
- **배경:** Flow 에서 썸네일 이미지 프롬프트로 그림을 4장씩 만듭니다.
  싱글 프롬프트가 곡 이미지 프롬프트와 같고, 그 곡 이미지를 이미 받아 두었으면 그 그림을 씁니다(크레딧 안 씀).
- **글씨:**
  - 큰 한글 문구는 가운데 조금 위에 흰 글씨와 검정 테두리로 화면 폭에 맞춰 크게 넣습니다. 너무 긴 줄은 두 줄로 나눕니다.
  - 영어 문구는 왼쪽 위에 작게 넣습니다.
  - 글꼴은 한글 **휴먼둥근헤드라인**, 영어·숫자 **Times New Roman Bold** 입니다. 한 줄에 섞여 있으면 글자마다 나눠 씁니다.
  - 캡컷 초안은 모든 글씨의 테두리 두께가 **60** 입니다.

### 저장 위치

```
F:\음악생성\<md 파일 이름>\썸네일\
   메인_한글1.jpg, 싱글1_한글1.jpg …   ← 완성 썸네일 (1920×1080, 2MB 이하)
   배경\메인\, 배경\싱글1\ …           ← Flow 에서 받은 배경 그림
   CapCut Drafts\                      ← 캡컷 초안 (글씨를 고칠 수 있음)
```

### 캡컷에서 고치기

- 캡컷 설정의 **초안 위치**를 그 앨범의 `썸네일\CapCut Drafts` 로 바꾸면 초안이 보입니다.
  예: `<md 이름> 썸네일 메인_한글1`
- 줄마다 글 상자가 따로 있어서 글·크기·위치를 하나씩 고칠 수 있습니다.
- 배경 그림은 캡컷의 '바꾸기'로 `배경\` 폴더의 다른 그림으로 바꿀 수 있습니다.

### 알아 둘 것

- 다시 실행하면 배경이 이미 있는 썸네일은 Flow 를 건너뛰고 글씨만 다시 얹습니다.
- 휴먼둥근헤드라인을 찾지 못하면 맑은 고딕 굵게로 대신하고 까만 창에 알려 줍니다.

## 2. 일괄 작업 — `일괄작업.bat`

md 파일 1개 이상을 넣으면 **노래 → 이미지·영상 → 썸네일**을 끝까지 혼자 합니다.

### 순서

1. `일괄작업.bat` 을 더블클릭합니다.
2. md 파일을 까만 창에 끌어다 놓고 Enter 를 누릅니다.
   - **1개, 2개, 3개 모두 됩니다.** 한꺼번에 놓아도 되고 하나씩 놓아도 됩니다.
   - 다 넣었으면 그냥 Enter 를 누릅니다.
3. md 마다 **AI 마스터링**을 묻습니다. **Enter 만 누르면 종류에 맞는 기본값**이 됩니다.
   - 경음악·클래식: Enter = **안 함**
   - 가요·칸쏘네·미사곡: Enter = **함**
   - 다르게 하고 싶을 때만 `y` 나 `n` 을 누릅니다.
4. 목록을 확인하고 `y` 를 누릅니다.
5. Flow 프로젝트가 안 열려 있으면 이때 열어 달라고 합니다. 열고 Enter 를 누릅니다.
6. 그다음은 끝까지 혼자 갑니다. **md 하나에 최대 3~4시간.** 크롬 창은 건드리지 마세요.

### md 마다 하는 일

| md 종류 | 노래 (CAVN) | 이미지 15장 + 영상 (Flow) | 썸네일 |
|---|---|---|---|
| 경음악·클래식 | 함 | 함 | 썸네일 문구가 있으면 함 |
| 가요·칸쏘네·미사곡 | 함 | 안 함 | 썸네일 문구가 있으면 함 |

### 알아 둘 것

- 한 단계가 실패해도 다음 단계·다음 md 로 넘어갑니다. 마지막에 **실패한 것만 모아서** 보여 줍니다.
- **다시 실행하면** 끝난 곡·트랙·썸네일은 건너뛰고 남은 것만 합니다.
- 실행 기록은 `F:\음악생성\<md 파일 이름>\일괄작업기록.txt` 에 남습니다. 밤새 돌린 뒤 아침에 확인하세요.
- CAVN 앨범을 자동으로 못 만들면 사람을 기다리지 않습니다. 그 md 의 노래 단계를 실패로 하고 넘어갑니다.
  CAVN 에서 앨범을 직접 만든 뒤 다시 실행하세요.
- 처음에는 md **1개**로 해 보고, 잘 되면 2개, 3개로 늘리세요.

## 3. 노래 순서 맞추기 — `노래순서맞추기.bat`

캡컷 조립 프로그램(대중가요 조립, 전곡 재조립, 클래식 일괄·두바퀴 조립)은 노래 파일을 **만든 날짜 순서**로 줄 세웁니다.
그래서 3·4번 곡을 나중에 받으면 맨 뒤로 가서 곡과 이미지 짝이 어긋났습니다.
이 프로그램은 노래 파일의 **날짜만** 트랙 순서(1번 → 2번 → …)로 바꿉니다. 파일 이름과 내용은 그대로입니다.

### 자동으로 하는 경우

CAVN 노래 프로그램(`CAVN_음악만들기.bat`, 메뉴, 일괄 작업)은 **끝날 때마다 자동으로** 맞춥니다.
따로 할 일이 없습니다.

### 직접 돌려야 하는 경우

- 예전에 받아 둔 앨범
- 노래 폴더를 **다른 드라이브로 복사한 뒤.** 복사하면 윈도우가 날짜를 복사한 시간으로 바꿉니다.

### 순서

1. `노래순서맞추기.bat` 을 더블클릭합니다.
2. 그 앨범의 md 파일을 끌어다 놓고 Enter 를 누릅니다.
3. `노래 파일 N개의 날짜를 트랙 순서로 맞췄습니다` 가 나오면 끝입니다.

### 알아 둘 것

- 노래 폴더는 `F:\음악생성\<md 파일 이름>\노래\` 입니다.
- 다른 곳에 있는 노래 폴더는 명령어로 맞춥니다.
  ```bat
  python song_order.py "앨범.md" --dir "D:\다른곳\노래"
  ```
- 한 곡 안에서는 `제목` → `제목 (1)` → `제목_mastered` 순서입니다.
- 확인 방법: 탐색기 `노래` 폴더에서 **만든 날짜**로 정렬하면 트랙 순서대로 나와야 합니다.

## 처음 써 볼 때 확인할 것

1. **썸네일:** 캡컷 초안에서 글꼴, 테두리 두께 60, 글씨 크기·위치가 맞는지 봅니다.
2. **일괄 작업:** md 1개로 끝까지 돌아가는지, `일괄작업기록.txt` 가 남는지 봅니다.
3. **노래 순서:** 받아 둔 앨범으로 한 번 돌려 봅니다. 탐색기 정렬과 캡컷 조립 결과가 맞는지 봅니다.

문제가 있으면 까만 창 화면이나 `일괄작업기록.txt` 를 보여 주세요.
