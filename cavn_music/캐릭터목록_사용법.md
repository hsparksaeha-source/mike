# 캐릭터목록 사용법

Flow 이미지·영상 프로그램과 일괄 작업이 곡마다 주인공 캐릭터를 올릴 때 보는 파일입니다.

- 파일 위치: `cavn_music\캐릭터목록.txt`
- 메모장으로 열어서 고칩니다. 저장할 때 인코딩은 그대로(UTF-8) 둡니다.
- `#` 으로 시작하는 줄은 설명이라 프로그램이 읽지 않습니다.

---

## 1. 파일 모양

```
프로젝트: 캐릭터목록

[칸쏘네1]
여: 쥴리
남: 마태오

[칸쏘네2]
여: 안나
남: 브루노

[20-40]
여: 소라
남: 서준

[50-60]
여: 순자
남: 정우

[클래식]
프로젝트: 누니 야니
캐릭터: 누니, 야니

[인물 설명]
쥴리: 키 185센티미터의 큰 키
안나: 키 185센티미터의 큰 키
마태오: 키 195센티미터의 큰 키
브루노: 키 195센티미터의 큰 키
```

| 줄 | 뜻 |
|---|---|
| `프로젝트: …` (맨 위) | 캐릭터를 만들어 둔 Flow 프로젝트 이름 (기본) |
| `[묶음 이름]` | 캐릭터 묶음의 시작 |
| `여:` / `남:` | 가요·칸쏘네의 여자·남자 주인공 |
| `캐릭터:` | 남·여 구분이 없는 캐릭터 (클래식의 누니·야니 등) |
| `프로젝트: …` (묶음 안) | 그 묶음 캐릭터만 들어 있는 Flow 프로젝트 이름 |
| `[인물 설명]` | 이미지·영상을 부탁할 때 함께 보내는 설명 (키 등) |

---

## 2. 가요·칸쏘네 (여: / 남:)

- 한 앨범에는 **한 묶음(여자 1명 + 남자 1명)** 만 씁니다.
- 일괄 작업이나 이미지 프로그램을 시작할 때 **묶음을 고르라고** 묻습니다.
- 곡마다 주인공은
  1. md 의 **`주인공 캐릭터`** 칸에 적힌 이름 (예: `소라`, `서준`, `소라와 서준`)
  2. 없으면 곡의 가수 성별 (여성 → 여자 주인공, 남성 → 남자 주인공, 듀엣 → 둘 다)
- 캐릭터는 맨 위 `프로젝트:` 에 적힌 Flow 프로젝트(기본 `캐릭터목록`)에서 불러옵니다.

## 3. 클래식 등 (캐릭터: + 묶음 프로젝트)

```
[클래식]
프로젝트: 누니 야니
캐릭터: 누니, 야니
```

- `프로젝트:` 에는 그 캐릭터들을 만들어 둔 **Flow 프로젝트 이름**을 적습니다.
- md 의 곡마다 **`주인공 캐릭터`** 칸에 이름을 적습니다.
  - `누니` / `야니` / `누니, 야니` (또는 `누니와 야니`) → 그 캐릭터를 올리고 이미지를 만듭니다.
  - `없음` 이나 빈칸 → 캐릭터 없이 만듭니다.
- 묶음을 고르라고 묻지 않습니다. 이름을 보고 알아서 묶음을 찾습니다.
- 시작 전에 "캐릭터를 올려서 만들 곡: 1번(누니), 3번(누니·야니) …" 처럼 보여 줍니다.

## 4. 인물 설명 (키 등)

```
[인물 설명]
안나: 키 185센티미터의 큰 키
브루노: 키 195센티미터의 큰 키
```

- 그 인물이 주인공인 곡은 이미지 요청 글의 **맨 앞과 맨 끝**, 그리고 영상 요청 글에 이렇게 들어갑니다.
  > 안나 키 185센티미터의 큰 키, 브루노 키 195센티미터의 큰 키, 이 키를 그대로 반영해서 가사에 맞게 이미지 15장 만들어 주세요.
- 키 말고 머리 모양·옷 등도 적을 수 있습니다.
- 너무 크게(거인처럼) 나오면 숫자를 줄이거나 "큰 키" 를 빼고 `키 185센티미터` 만 적습니다.
- 넣고 싶지 않은 사람은 그 줄을 지우거나 맨 앞에 `#` 을 붙입니다.

---

## 5. 새 캐릭터 묶음 넣기

1. Flow 에 새 프로젝트를 만들고 캐릭터를 만들어 이름을 붙입니다.
2. `캐릭터목록.txt` 맨 아래(또는 `[인물 설명]` 위)에 적습니다.

   남·여 주인공이면
   ```
   [새 묶음 이름]
   프로젝트: Flow 프로젝트 이름
   여: 여자 이름
   남: 남자 이름
   ```
   남·여 구분이 없으면
   ```
   [새 묶음 이름]
   프로젝트: Flow 프로젝트 이름
   캐릭터: 이름1, 이름2
   ```
   (맨 위 `프로젝트: 캐릭터목록` 에 만들어 두었다면 묶음 안의 `프로젝트:` 줄은 빼도 됩니다.)
3. md 의 곡마다 `주인공 캐릭터` 칸에 그 이름을 적습니다.

## 6. 꼭 지킬 것

- Flow 의 **프로젝트 이름·캐릭터 이름과 글자 하나까지 똑같이** 적습니다 (띄어쓰기 포함).
- 같은 이름의 캐릭터가 Flow 프로젝트 안에 **하나만** 있어야 합니다.
- 같은 캐릭터 이름을 두 묶음에 겹쳐 적지 않습니다.
- 철자가 조금 달라도(줄리 → 쥴리) 목록에서 하나로 정해지면 알아서 맞춥니다.
- 새 얼굴이 필요하면 이름은 그대로 두고 Flow 에서 캐릭터 그림만 바꾸면 됩니다.

## 7. 새 프로그램(zip)을 받을 때

새 zip 을 ① 폴더에 덮어쓰면 `캐릭터목록.txt` 도 새 파일로 바뀔 수 있습니다.
**덮어쓰기 전에 지금 `캐릭터목록.txt` 를 다른 곳에 복사해 두었다가**, 덮어쓴 뒤 다시 넣으세요.

## 8. 문제가 생기면

| 까만 창 글 | 할 일 |
|---|---|
| 캐릭터목록에 없는 이름: … | md 의 `주인공 캐릭터` 칸 이름과 `캐릭터목록.txt` 이름이 같은지 확인 |
| 프로젝트 '…' 를 찾지 못했습니다 | `프로젝트:` 이름이 Flow 프로젝트 이름과 똑같은지 확인 |
| 캐릭터 '…' 을(를) 찾지 못했습니다 | Flow 그 프로젝트 안의 캐릭터 이름 확인 |
| 애셋 고르기 창에서 '캐릭터'를 찾지 못했습니다 | Flow 프롬프트 칸이 오른쪽 에이전트 창 안에 있는지 확인 후 다시 실행 |
