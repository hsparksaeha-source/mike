# CAVN AI 자동 곡 만들기 + 다운로드

> **한 번에 실행:** `음악_이미지_자동화.bat` → md 파일 끌어다 놓기 → `1` 음악 / `2` 이미지·영상 / `3` 둘 다 / `4` 썸네일

Claude가 만든 음악 md 파일을 넣으면 [CAVN AI](https://cavn.ai/create)에서 곡을 차례로 만들고,
만들어진 2곡을 F드라이브 폴더에 내려받습니다.

## 실행

1. (처음 한 번) 저장소 맨 위 폴더의 `install.bat` 실행
2. **`CAVN_음악만들기.bat`** 더블클릭 → md 파일을 까만 창에 끌어다 놓고 Enter
   (md 파일을 bat 아이콘 위에 바로 끌어다 놓아도 됩니다)
3. 첫 화면에서 **이 앨범 전체를 AI 마스터링할지** `y` / `n` (크레딧이 들어서 실행할 때마다 한 번 물어봅니다)
4. 곡 목록과 예상 크레딧을 확인하고 `y` 입력
5. 처음 실행이면 크롬이 열립니다. CAVN에 로그인하고 까만 창에서 Enter
   (로그인은 내 사용자 폴더의 `CavnFlowChromeProfile` 에 저장되어, 프로그램을 새로 받아도 **한 번만** 하면 됩니다.
    CAVN·Flow 가 같은 전용 크롬을 함께 씁니다. 평소 크롬과는 따로라서 거기서도 한 번씩 로그인해 주세요.)

실행 중에는 크롬 창을 건드리지 말고 지켜보기만 해 주세요.

## 하는 일

1. **앨범 만들기**: 앨범 이름은 md 파일 이름 그대로 (이미 있으면 그 앨범 사용)
2. 곡 만들기 화면 왼쪽 아래와 오른쪽 위의 앨범 칸에서 그 앨범 선택
3. 곡마다 **커스텀 모드**에서 입력 → **[지금 만들기]**

   | | 가요/팝 | 클래식 |
   |---|---|---|
   | 연주곡 스위치 | 끔 | 켬 |
   | 제목 | md의 제목 (한글 괄호 설명은 뺌) | md의 제목 |
   | 가사 칸 | md의 가사 | (없음) |
   | 음악 스타일 칸 | 장르 + 스타일 | 스타일 + 줄바꿈 + 구조 태그 |
   | 고급 설정 · 제외 스타일 | 머리말의 '공통 Exclude Styles' | 곡마다 'Exclude Styles' |

   종류는 md 파일을 보고 자동으로 정합니다 ('가사(구조 태그)'가 있으면 클래식).
4. 2곡이 다 만들어질 때까지 기다림 (최대 30분)
5. 두 곡을 다 받은 뒤 **wav 파일 크기**로 긴 곡·짧은 곡을 정함 (같은 형식이라 큰 파일 = 긴 곡)
6. 앨범에 이 제목의 곡이 이미 2개 있으면(지난번에 못 받은 곡) **새로 만들지 않고 그 곡을 받음** (크레딧 절약)
7. (마스터링을 골랐으면) **[AI 마스터링] → '밝고 선명한' → [AI 처리 시작 (5 크레딧)]** → 끝나면 다운로드
   → `제목_mastered.wav`. 가요 캡컷 조립 프로그램이 읽는 이름입니다.
   **크레딧을 아끼려고 각 제목의 긴 곡 하나만** 마스터링합니다 (10곡 앨범이면 마스터링 50크레딧).

## 저장되는 파일

`F:\음악생성\<md 파일 이름>\노래\` (캡컷 조립 프로그램이 읽는 구조)

| | 긴 곡 | 짧은 곡 |
|---|---|---|
| MP3 | `제목.mp3` | `제목 (1).mp3` |
| WAV | `제목.wav` | `제목 (1).wav` |
| 스크롤 가사 (LRC) | `제목.lrc` | `제목 (1).lrc` |
| 곡 커버 | `제목.jpg` | `제목 (1).jpg` |
| 텍스트 가사 - 구간 라벨 유지 | `제목_구간라벨.txt` | |
| 텍스트 가사 - 가사 본문만 | `제목_가사본문.txt` | |
| AI 마스터링 (선택) | `제목_mastered.wav` | (하지 않음) |

가사 비디오와 창작 증명서는 받지 않습니다.

- 재생바에서 길이를 못 읽으면 두 곡을 모두 받은 뒤 **wav 파일 크기**(=길이)로 긴 곡을 정합니다.
- `제목.wav`와 `제목 (1).wav`가 이미 있는 곡은 건너뜁니다.
  중간에 멈추거나 실패한 곡이 있으면 **다시 실행하면 남은 곡만** 만듭니다.
- 곡은 받았는데 마스터링 파일만 없으면, 곡을 새로 만들지 않고 **마스터링만** 합니다.
- 한 곡이 실패해도 다음 곡은 계속 진행하고, 마지막에 실패한 곡을 알려 줍니다.

## 캡컷 조립 순서 (노래 파일 날짜)

캡컷 조립 프로그램(대중가요 조립, 전곡 재조립, 클래식 일괄·두바퀴 조립)은 노래 파일을 **만든 날짜 순서**로 줄 세웁니다.
그래서 3·4번 곡을 나중에 받으면 맨 뒤로 가서 곡과 이미지 짝이 어긋났습니다.

- 이제 CAVN 노래 프로그램이 끝날 때마다 `노래\` 폴더 파일의 날짜를 **1번 곡 → 2번 곡 … 순서로 자동으로 맞춥니다**
  (파일 내용·이름은 그대로, 날짜만 바꿈). 받을 곡이 없어서 바로 끝나도 맞춥니다.
- 이미 받아 둔 앨범이나, 노래 폴더를 **다른 드라이브로 복사해서** 날짜가 다시 섞였으면
  **`노래순서맞추기.bat`** 에 그 md 파일을 끌어다 놓으세요. (다른 곳의 노래 폴더: `python song_order.py "앨범.md" --dir "D:\다른곳\노래"`)
- 한 곡 안에서는 `제목` → `제목 (1)` → `제목_mastered` 순서입니다.

## 명령어로 실행하기 (선택)

```bat
python cavn_maker.py "카페소네트5_2장.md"
python cavn_maker.py "카페소네트5_2장.md" --out "F:\다른폴더"
python cavn_maker.py "카페소네트5_2장.md" --only 3,7
python cavn_maker.py "카페소네트5_2장.md" --master 0     (마스터링 질문 없이 '안 함')
python cavn_maker.py "카페소네트5_2장.md" --dry-run      (md 파일만 읽어 보고 끝냄)
```

## 바꿀 수 있는 설정 (`cavn_maker.py` 맨 위)

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `DEFAULT_OUT` | `F:\음악생성` | 저장 폴더 |
| `POP_STYLE_INCLUDES_GENRE` | `True` | 가요/팝 음악 스타일 칸에 장르도 넣을지 |
| `GENERATE_TIMEOUT_SEC` | 1800 | 곡 생성 최대 대기 (초) |
| `MASTER_STYLE` | `밝고 선명한` | AI 마스터링 스타일 |
| `DEBUG_PORT` | 9224 | 크롬 연결 번호 (다른 자동 프로그램과 겹치지 않게) |

# Google Flow 이미지 15장 + 영상 1개 (경음악·클래식)

같은 md 파일로 [Google Flow](https://flow.google.com/)에서 트랙마다 이미지 15장과 영상 1개를 만듭니다.

- 이미지: `F:\음악생성\<md 파일 이름>\이미지\1번` ~ `\16번` 번호 폴더 (**이미지만**, 캡컷 클래식 조립 프로그램이 읽는 구조)
- 영상: `F:\음악생성\<md 파일 이름>\장면\1.mp4` ~ `16.mp4` (이미지와 섞이지 않게 따로)
이미지 프롬프트가 있는 **경음악·클래식 md만** 됩니다 (가요·샹송 md는 뮤직비디오 콘셉트만 있어서 건너뜀).

## 실행

1. **`Flow_이미지영상만들기.bat`** 더블클릭 → md 파일을 까만 창에 끌어다 놓고 Enter
2. 트랙 목록 확인 후 `y`
3. 크롬이 열리면 Flow 에 로그인하고 **작업할 프로젝트를 열고** 까만 창에서 Enter
   (로그인은 CAVN 과 같은 전용 크롬에 저장. 다음부터는 프로젝트만 열면 됨)
4. "기존 이미지 쓰기 (y/n)": 첫 트랙의 이미지 15장을 지난번에 Flow 에서 이미 만들어 두었으면 `y`
   → 새로 만들지 않고 Flow 화면 맨 앞의 15장으로 영상·컬렉션만 합니다. 보통은 `n`
   이어서 "기존 영상 쓰기 (y/n)": 영상도 이미 있으면 `y` → 컬렉션·다운로드만 (크레딧 안 씀)

## 트랙마다 하는 일

1. 아래 프롬프트 칸(에이전트)에 **이미지 프롬프트 + "이미지 15장을 만들어 줘"** → 15장 완성 기다림
2. 새 이미지 중 **화면 맨 끝 것(제일 처음 만든 것)** 을 프롬프트 칸에 끌어다 놓고
   **영상 프롬프트**(경음악은 '뮤직 비디오 콘셉트') + "이 이미지로 영상을 만들어 줘" → 영상 완성 기다림
3. 오른쪽 위 **[+] → [새 컬렉션]** → 이미지 15장을 하나씩 컬렉션에 끌어다 넣음 (영상은 그대로)
4. 컬렉션에 마우스를 올리고 **[⋮] → [컬렉션 다운로드]** → 내려온 15장을 `이미지\N번\` 에 저장
   (다운로드하면서 뜬 창은 다 받은 뒤 닫음)
5. 영상은 `장면\N.mp4` 로 따로 저장

- 이미지 15장과 영상이 이미 있는 트랙은 건너뜁니다. 15장보다 적게 받아졌으면 다음 실행 때 그 트랙을 다시 합니다. 실패한 트랙은 다시 실행하면 그 트랙부터 합니다.
- 한 트랙이 실패해도 다음 트랙은 계속합니다.

```bat
python flow_maker.py "낭만오케스트라3집.md" --only 3      (3번 트랙만)
python flow_maker.py "낭만오케스트라3집.md" --images 10   (이미지 10장씩)
python flow_maker.py "낭만오케스트라3집.md" --dry-run     (목록만 확인)
```

# 유튜브 썸네일 만들기 (Flow 배경 + 캡컷 초안)

md 파일 맨 아래 유튜브 SEO 부분의 **썸네일 문구**와 **썸네일 이미지 프롬프트**로 썸네일을 만듭니다.

- 메인(전곡) 1개 + 싱글(보통 3개). 미사곡·클래식처럼 싱글이 없는 md 는 메인만.
- 곡(트랙)마다 적힌 썸네일 문구는 쓰지 않습니다.

## 실행

1. **`썸네일만들기.bat`** 더블클릭 → md 파일을 끌어다 놓고 Enter
   (`음악_이미지_자동화.bat` 에서 `4` 를 골라도 됩니다)
2. 읽은 문구 목록을 확인하고 `y`
3. Flow 프로젝트를 열어 두면 배경 그림을 만듭니다 (썸네일마다 4장)
   - 싱글 프롬프트가 곡 이미지 프롬프트와 같고 `이미지\N번` 에 그 곡 이미지가 있으면 **그것을 씀** (크레딧 안 씀)

## 만들어지는 것

`F:\음악생성\<md 파일 이름>\썸네일\`

| | |
|---|---|
| `메인_한글1.jpg`, `메인_한글2.jpg`, `싱글1_한글1.jpg` … | 완성 썸네일 (1920×1080, 2MB 이하). 문구 안마다 한 장 |
| `배경\메인\`, `배경\싱글1\` … | Flow 에서 받은 배경 그림 (첫 장을 씀) |
| `CapCut Drafts\<md 이름> 썸네일 메인_한글1` … | 같은 썸네일을 캡컷에서 고칠 수 있는 캡컷 초안 |

음악(`노래\`)·이미지(`이미지\`)·영상(`장면\`)과 같은 `F:\음악생성\<md 파일 이름>\` 아래에 모두 모입니다.
캡컷에서 초안을 보려면 캡컷 설정의 **초안 위치**를 이 `썸네일\CapCut Drafts` 폴더로 바꾸세요
(다른 캡컷 조립 프로그램의 `CapCut Drafts` 폴더와 같은 방식). 캡컷을 닫은 채로 프로그램을 돌리고, 끝나면 캡컷을 여세요.

- 큰 한글 문구: 가운데 조금 위, 흰 글씨 + 굵은 검정 테두리, 화면 폭에 맞춰 최대한 크게. 너무 긴 줄은 두 줄로 나눕니다.
- 영어 문구: 왼쪽 위에 작게 (Times New Roman Bold).
- 글꼴: 한글 **휴먼둥근헤드라인**, 영어·숫자 **Times New Roman Bold**. 한 줄 안에 섞여 있으면 글자마다 나눠 씀.
  휴먼둥근헤드라인이 없으면 맑은 고딕 굵게로 대신하고 까만 창에 알려 줍니다.
- 캡컷에서는 줄마다 글 상자가 따로 있어서 글·크기·위치를 하나씩 고칠 수 있습니다. 배경 그림은 캡컷의 '바꾸기'로 `배경\` 폴더의 다른 그림으로 바꾸면 됩니다.
- 다시 실행하면 배경이 이미 있는 썸네일은 Flow 를 건너뛰고 글씨만 다시 얹습니다.

```bat
python thumb_maker.py "낭만오케스트라3집.md" --no-flow     (Flow 없이, 받아 둔 배경으로만)
python thumb_maker.py "낭만오케스트라3집.md" --images 2    (배경 그림 2장씩)
python thumb_maker.py "낭만오케스트라3집.md" --capcut "D:\캡컷초안"   (캡컷 초안을 다른 폴더에)
```

# 일괄 작업 (노래 → 이미지·영상 → 썸네일 한 번에)

기존 프로그램은 그대로 두고, 그것들을 차례로 끝까지 돌리는 프로그램입니다.

## 실행

1. **`일괄작업.bat`** 더블클릭
2. md 파일을 까만 창에 끌어다 놓고 Enter. **1개도, 2개도, 3개도** 됩니다 (한꺼번에 놓아도 되고 하나씩 놓아도 됨).
   다 넣었으면 그냥 Enter.
3. md 마다 **AI 마스터링** 질문 → **Enter 만 누르면 종류에 맞는 기본값**
   - 경음악·클래식(연주곡): 기본 **안 함**
   - 가요·칸쏘네·미사곡(가사 있는 곡): 기본 **함**
   - 다르게 하고 싶을 때만 `y` / `n`
4. 목록을 확인하고 `y` → Flow 프로젝트가 열려 있는지 확인 (없으면 지금 열어 달라고 함)
5. 그다음은 끝까지 사람 손 없이 갑니다. **md 하나에 최대 3~4시간.** 크롬 창은 건드리지 마세요.

## md 마다 하는 일

| | 노래 (CAVN) | 이미지 15장 + 영상 (Flow) | 썸네일 |
|---|---|---|---|
| 경음악·클래식 | ○ | ○ | 썸네일 문구가 있으면 ○ |
| 가요·칸쏘네·미사곡 | ○ | (안 함) | 썸네일 문구가 있으면 ○ |

- 한 단계가 실패해도 다음 단계·다음 md 로 넘어가고, 마지막에 실패한 것만 모아서 보여 줍니다.
- **다시 실행하면** 끝난 곡·트랙·썸네일은 건너뛰고 남은 것만 합니다.
- 실행 기록: `F:\음악생성\<md 파일 이름>\일괄작업기록.txt` (밤새 돌린 뒤 아침에 확인)
- CAVN 앨범을 자동으로 못 만들면 (사람을 기다리지 않고) 그 md 의 노래 단계를 실패로 넘깁니다.

```bat
python batch_maker.py "앨범1.md" "앨범2.md"          (md 를 바로 지정)
python batch_maker.py "앨범1.md" --master 0 --yes    (질문 없이: 마스터링 안 함, 바로 시작 — 나중에 예약 실행용)
```
