# CAVN AI 자동 곡 만들기 + 다운로드

Claude가 만든 음악 md 파일을 넣으면 [CAVN AI](https://cavn.ai/create)에서 곡을 차례로 만들고,
만들어진 2곡을 F드라이브 폴더에 내려받습니다.

## 실행

1. (처음 한 번) 저장소 맨 위 폴더의 `install.bat` 실행
2. **`CAVN_음악만들기.bat`** 더블클릭 → md 파일을 까만 창에 끌어다 놓고 Enter
   (md 파일을 bat 아이콘 위에 바로 끌어다 놓아도 됩니다)
3. 첫 화면에서 **이 앨범 전체를 AI 마스터링할지** `y` / `n` (크레딧이 들어서 실행할 때마다 한 번 물어봅니다)
4. 곡 목록과 예상 크레딧을 확인하고 `y` 입력
5. 처음 실행이면 크롬이 열립니다. CAVN에 로그인하고 까만 창에서 Enter
   (로그인은 `browser_profile` 폴더에 저장되어 다음부터는 바로 시작)

실행 중에는 크롬 창을 건드리지 말고 지켜보기만 해 주세요.

## 하는 일

1. **앨범 만들기**: 앨범 이름은 md 파일 이름 그대로 (이미 있으면 그 앨범 사용)
2. 곡 만들기 화면 왼쪽 아래와 오른쪽 위의 앨범 칸에서 그 앨범 선택
3. 곡마다 **커스텀 모드**에서 입력 → **[지금 만들기]**

   | | 가요/팝 | 클래식 |
   |---|---|---|
   | 연주곡 스위치 | 끔 | 켬 |
   | 제목 | md의 제목 (한글 괄호 설명은 뺌) | md의 제목 |
   | 가사 칸 | md의 가사 | (없음) |
   | 음악 스타일 칸 | 장르 + 스타일 | 스타일 + 줄바꿈 + 구조 태그 |
   | 고급 설정 · 제외 스타일 | 머리말의 '공통 Exclude Styles' | 곡마다 'Exclude Styles' |

   종류는 md 파일을 보고 자동으로 정합니다 ('가사(구조 태그)'가 있으면 클래식).
4. 2곡이 다 만들어질 때까지 기다림 (최대 15분)
5. 앨범 자켓을 눌러 아래 재생바에서 **곡 길이**를 읽고 바로 멈춤
6. **긴 곡부터** 내려받기
7. (마스터링을 골랐으면) **[AI 마스터링] → '밝고 선명한' → [AI 처리 시작 (5 크레딧)]** → 끝나면 다운로드
   → `제목_mastered.wav` (두 곡 모두면 `제목 (1)_mastered.wav`도). 가요 캡컷 조립 프로그램이 읽는 이름입니다.

## 저장되는 파일

`F:\음악생성\<md 파일 이름>\노래\` (캡컷 조립 프로그램이 읽는 구조)

| | 긴 곡 | 짧은 곡 |
|---|---|---|
| MP3 | `제목.mp3` | `제목 (1).mp3` |
| WAV | `제목.wav` | `제목 (1).wav` |
| 스크롤 가사 (LRC) | `제목.lrc` | `제목 (1).lrc` |
| 곡 커버 | `제목.jpg` | `제목 (1).jpg` |
| 텍스트 가사 - 구간 라벨 유지 | `제목_구간라벨.txt` | |
| 텍스트 가사 - 가사 본문만 | `제목_가사본문.txt` | |
| AI 마스터링 (선택) | `제목_mastered.wav` | `제목 (1)_mastered.wav` (두 곡 모두일 때) |

가사 비디오와 창작 증명서는 받지 않습니다.

- 재생바에서 길이를 못 읽으면 두 곡을 모두 받은 뒤 **wav 파일 크기**(=길이)로 긴 곡을 정합니다.
- `제목.wav`와 `제목 (1).wav`가 이미 있는 곡은 건너뜁니다.
  중간에 멈추거나 실패한 곡이 있으면 **다시 실행하면 남은 곡만** 만듭니다.
- 곡은 받았는데 마스터링 파일만 없으면, 곡을 새로 만들지 않고 **마스터링만** 합니다.
- 한 곡이 실패해도 다음 곡은 계속 진행하고, 마지막에 실패한 곡을 알려 줍니다.

## 명령어로 실행하기 (선택)

```bat
python cavn_maker.py "카페소네트5_2장.md"
python cavn_maker.py "카페소네트5_2장.md" --out "F:\다른폴더"
python cavn_maker.py "카페소네트5_2장.md" --only 3,7
python cavn_maker.py "카페소네트5_2장.md" --master 0     (마스터링 질문 없이 '안 함')
python cavn_maker.py "카페소네트5_2장.md" --dry-run      (md 파일만 읽어 보고 끝냄)
```

## 바꿀 수 있는 설정 (`cavn_maker.py` 맨 위)

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `DEFAULT_OUT` | `F:\음악생성` | 저장 폴더 |
| `POP_STYLE_INCLUDES_GENRE` | `True` | 가요/팝 음악 스타일 칸에 장르도 넣을지 |
| `GENERATE_TIMEOUT_SEC` | 900 | 곡 생성 최대 대기 (초) |
| `MASTER_STYLE` | `밝고 선명한` | AI 마스터링 스타일 |
| `MASTER_TARGET` | `1` | 마스터링할 때 1=긴 곡만, 2=두 곡 모두 |
| `DEBUG_PORT` | 9224 | 크롬 연결 번호 (다른 자동 프로그램과 겹치지 않게) |

# Google Flow 이미지 15장 + 영상 1개 (경음악·클래식)

같은 md 파일로 [Google Flow](https://flow.google.com/)에서 트랙마다 이미지 15장과 영상 1개를 만들어
`F:\음악생성\<md 파일 이름>\이미지\1` ~ `\16` 번호 폴더에 넣습니다 (캡컷 클래식 조립 프로그램이 읽는 구조).
이미지 프롬프트가 있는 **경음악·클래식 md만** 됩니다 (가요·샹송 md는 뮤직비디오 콘셉트만 있어서 건너뜀).

## 실행

1. **`Flow_이미지영상만들기.bat`** 더블클릭 → md 파일을 까만 창에 끌어다 놓고 Enter
2. 트랙 목록 확인 후 `y`
3. 크롬이 열리면 Flow 에 로그인하고 **작업할 프로젝트를 열고** 까만 창에서 Enter
   (로그인은 `flow_profile` 폴더에 저장. 다음부터는 프로젝트만 열면 됨)

## 트랙마다 하는 일

1. 아래 프롬프트 칸(에이전트)에 **이미지 프롬프트 + "이미지 15장을 만들어 줘"** → 15장 완성 기다림
2. 새 이미지 중 **화면 맨 끝 것(제일 처음 만든 것)** 을 프롬프트 칸에 끌어다 놓고
   **영상 프롬프트**(경음악은 '뮤직 비디오 콘셉트') + "이 이미지로 영상을 만들어 줘" → 영상 완성 기다림
3. 오른쪽 위 **[+] → [새 컬렉션]** → 이미지 15장을 하나씩 컬렉션에 끌어다 넣음 (영상은 그대로)
4. 컬렉션에 마우스를 올리고 **[⋮] → [컬렉션 다운로드]** → 15장을 `이미지\N\` 에 저장
   (압축 파일로 오면 풀어서 넣고, 다운로드 때문에 열린 창은 닫음)
5. 영상도 `이미지\N\N_영상.mp4` 로 저장

- 이미지와 영상이 이미 들어 있는 번호 폴더는 건너뜁니다. 실패한 트랙은 다시 실행하면 그 트랙부터 합니다.
- 한 트랙이 실패해도 다음 트랙은 계속합니다.

```bat
python flow_maker.py "낭만오케스트라3집.md" --only 3      (3번 트랙만)
python flow_maker.py "낭만오케스트라3집.md" --images 10   (이미지 10장씩)
python flow_maker.py "낭만오케스트라3집.md" --dry-run     (목록만 확인)
```
